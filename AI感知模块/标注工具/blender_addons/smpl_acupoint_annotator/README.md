# SKEL/SMPL-X 穴位 Atlas 标注插件 v0.6.3

v0.6 将正式产品路线拆分为两个互不叠加的模型入口：

- **SKEL 躯干与四肢 Atlas**：当前正式主线。穴位直接绑定 SKEL 原生皮肤；同模型原生骨架可开关。
- **SMPL-X 独立研究**：保留完整可调模型，不加载或拟合 SKEL。

旧 v0.5 的 SMPL-X→SKEL 项目拟合不再进入正式标注流程。

## 医生流程

1. 通过启动器创建独立工作副本。
2. 选择女性或男性 SKEL；建立母版时选择“规范 Atlas”。
3. 填写标准编码、中文名称、身体分区和中线/左侧/右侧。
4. 点击“开始点选人体表面”，再单击 SKEL 皮肤。
5. 确认无误后点击“保存本次标注”；只有主动保存才会记录，未保存的修改不会提交。

内部研究模式可导入已保存的 `*_正式标注_最新.json`。JSON 读取兼容 UTF-8 BOM；如果误选同一会话的“本次标注信息.json”，插件会定位对应的正式标注文件。尚未主动保存的会话不会出现在“继续已有标注”中。

正式 SKEL Atlas 拒绝头面部和手部区域。左右穴位必须分别建立，例如 `BL23_L` 与 `BL23_R`。

## 数据格式

正式 schema 为 `smpl-acupoint-annotation-v5`。每个点以目标皮肤的三角面编号与重心坐标为主位置，同时记录：

- 模型家族、性别、模板 ID、顶点/三角面数量和有序拓扑指纹；
- 医生、任务、会话、标准编码、中文名称、侧别与身体分区；
- SKEL 是否为原生主模型、骨架是否显示/使用，以及 `cross_model_registration_used=false`；
- 派生局部/世界坐标和法向。

插件兼容读取 v1–v4 JSON，但只有模型族和完整拓扑匹配时才可恢复。SKEL/SMPL 与 SMPL-X 的面编号不能直接混用。

## 模式边界

- 规范 Atlas：锁定 SKEL 的 10 个体型参数和 46 个生物力学姿态参数；意外改变后正式保存会被阻止。
- 内部研究：允许调整简化 β0/β1、姿态并重新计算原生皮肤、骨架和关节。
- 骨架永远不可选中，穴位只能点在皮肤上。

SKEL 骨架是结构先验，不是患者 CT 或医学影像真值。Blender 坐标也不是机器人执行坐标。
