# 医生穴位标注工作台（含固定 SMPL-X Body 模板）

本包已经包含便携 Blender、中文穴位标注插件，以及中性、女性、男性三个固定 SMPL-X Body 医生模板。

不需要安装 Blender、Python 或插件，也不需要首次下载模型。解压后直接双击：

`开始使用_医生穴位标注工作台.cmd`

填写医生/标注人编号、任务/受试者编号，选择模板性别，然后点击“开始全身穴位标注”。

## 模型边界

本包内置的是 SMPL-X Body（CC BY 4.0）固定模板，不是含完整体型参数和生成工具的 SMPL-X Model：

- 保留医生标注需要的全身、双手、手指和头面部表面；
- 移除了 300 个身份/体型 Shape blendshapes 和 100 个表情 blendshapes；
- 不包含 SMPL-X 官方生成工具和原始 Model 数据；
- 医生版不提供胖瘦、身份体型或表情调整。

许可与署名见根目录 `SMPL-X_BODY_许可与署名.md`。请勿删除该文件。

SKEL 暂留内部研究，未打入本医生包，也没有在医生界面中伪造未经验证的骨架叠加。

详细步骤见 `docs/医生快速开始.html`。
