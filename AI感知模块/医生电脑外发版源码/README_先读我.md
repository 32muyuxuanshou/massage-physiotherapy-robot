# 医生穴位标注工作台（医生电脑版）

本包已经包含便携 Blender 和中文穴位标注插件，不需要安装 Blender、Python 或插件。

第一次使用前，实际使用者需要从 SMPL-X 官方网站取得自己的 Blender Add-on ZIP。双击 `开始使用_医生穴位标注工作台.cmd`，选择这一个 ZIP；程序会在本机自动生成中性、女性、男性三个空白模板。

首次配置所需文件：

1. SMPL-X 官方 Blender Add-on ZIP，应包含 `blender_manifest.toml` 和 `data` 模型文件。

重要：首次配置界面中的勾选框只是确认，不会授予模型许可。文件必须由实际使用者本人从官方渠道取得。配置后生成的 `.blend` 模板仍受原许可约束，不能转发给未授权人员。

v2.1 医生正式标注只使用 SMPL-X。SKEL 暂留在内部研究环境，待配准参考层验证后再进入医生端。

完成配置后，以后只需双击 `开始使用_医生穴位标注工作台.cmd`。

详细步骤见 `docs/医生快速开始.html`。
