## 复现入口

- run_batch.py：在既有服务器 venv 下使用 --pilot 指定 S01 工程根目录；与 input、input_manifest.json 同目录。S01 prediction.npz 必须存在。完整进程日志见 server_snapshot/batch.log。
- project_engineering_points.py：在仓库内当前目录，使用 SKEL 的现有 Python 环境，读取冻结工程 Atlas 与对应资产；输出 JSON。
- render_engineering_points.py：使用系统 Python 与 Pillow，只渲染 JSON 中的工程点。

旧 input_manifest.json 内的选帧状态来自原始采样记录，不代表当前运行结果；当前推理状态以 server_snapshot/batch_status.json 为准。
