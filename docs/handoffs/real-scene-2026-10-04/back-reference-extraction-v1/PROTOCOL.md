# BACK_REFERENCE_EXTRACTION_V1

冻结时间：2026-10-04，正式几何参考误差尚未计算。

目标：仅输入30份已核验的真实PCdare/IIR背部XYZ扫描，输出可观察的几何纵向曲线；评价其与作者体表画线的差异。不输入原标记、画线、参考坐标或医学标签。扫描已由源作者裁成背部，这不是完整RGB-D自动人体分割。

三方法全部报告：BOUNDARY_CENTER、SYMMETRY_DP、GROOVE_DP。前者逐纵向截面取5%/95%横向边界中点；后二者分别最小化左右深度差、追踪局部深度凹槽，加相同连续性约束。原XYZ坐标方向沿数据来源保留；不将输出命名为某椎体或医学后正中线。

固定配置：横向网格2 mm、纵向网格5 mm、XY支持半径3 mm；纵向使用源点5%—95%分位；横向搜索边界中心±60 mm。局部平滑σ=(1 row,2 columns)，沟槽背景σ=(1 row,5 columns)。镜像偏移20/35/50/65 mm，至少3对支持；每行去除一次线性倾斜。两DP数据项以3 mm归一，中心惩罚0.1*(偏移/60 mm)^2；相邻行位移≤8 mm，位移惩罚0.15*(位移/4 mm)^2。输出最后回绑原扫描最近XY点。不得据评价结果调整配置。

三个估计器运行完、输出SHA冻结后，独立评价器才读取作者画线。共同评价为画线原Y值与三曲线Y域交集；逐点同Y线性插值，报告横向偏差及三维位置差median/P95/max。未覆盖端点计入coverage，不用降覆盖率换低分。另报告连续折线距离作为支持，不能替代同Y对应评价。全部30扫描及失败保留；每扫描先汇总，再对扫描等权取median；不称30个独立人物或全新泛化。

输出：90曲线缓存、90方法/扫描结果、逐画线点结果、30全量图、汇总、输入身份和估计/评价时间顺序。缓存可独立复算。没有训练、SAM推理、MHR拟合、穴位真值或机器人治疗执行。

单项完成后直接进入俯卧数据的同类几何提取及表面坐标接口；不以此画线误差作为俯卧穴位精度。
