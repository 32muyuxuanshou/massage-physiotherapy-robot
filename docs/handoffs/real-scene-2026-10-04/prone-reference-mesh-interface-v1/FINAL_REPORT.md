## 跑通的流程

现有RGB冻结后背ROI → 原空间块train点交集 → 三个XYZ几何提取器 → 同Y九个ENG探针 → 固定Official/Rigid/Rigid+D后背2152面最近投影 → face_id/barycentric/xyz/normal → 离线JSON接口。

查询与输出均为历史近似相机米制坐标。探针的0.1…0.9仅是共同曲线域的工程分位，不是骨度分寸、椎体或穴位。法向由原三角面绕序计算，不能直接当已验证机器人接触方向。[实际导出的9点JSON](ENGINEERING_TARGETS_EXAMPLE.json)、[导出程序](code/export_targets.py)。

原20人及4开发/16已消费测试角色不变。实际使用点索引与heldout交集为零；所有曲线回绑原训练点，全部Mesh缓存未改。算法和参数与上一轮30扫描提取完全相同，失败不以填深度/放宽参数掩盖。[执行前协议](PROTOCOL.md)、[实际配置](CONFIG.json)、[全部曲线记录](CURVE_RESULTS.csv)。

## 下一步判断

30扫描的沟槽画线差异3.69 mm不能迁移成衣物俯卧精度。当前可保留本接口和Rigid/RigidD几何基线，但自动几何曲线不应直接驱动穴位规则。

紧接着比较**固定拓扑 / 原RBF / 非负有界参考插值**：沿已有受控对应数据，四参考只作为输入、另外四点考试，检查能否减少噪声放大而保留切向纠正。它解决对应机制，不以“稳住错误衣物线”冒充医学准确率。后续真实个体化仍需要可观察、明确身份的参考与独立目标；当前不启动穴位伪标签训练。
