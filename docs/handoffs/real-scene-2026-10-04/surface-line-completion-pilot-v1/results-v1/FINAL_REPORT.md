# 真实体表线学习：实际执行结果 V1

2026-10-05完成交付。**六个模型实际训练完成。缺失块增强改善了参考线提取，但这不是 SAM3D 微调，也不是穴位定位精度验证。**

## 实际做了什么

服务器恢复后，重新同步原七个脚本与协议，核对环境、数据和代码哈希，完成数据准备及模型正向/反向检查。使用 GPU0 的一张 2080Ti，训练普通策略 `NO_BLOCK_AUG` 和缺失块增强策略 `BLOCK_AUG`，各初始化0/1/2、各120轮。模型是119,057参数的小型四通道UNet，输入为128×128的几何深度、有效区域、X/Y信息，输出横向参考线位置。

30份PCdare/IIR真实XYZ背部扫描，按预先冻结的SHA排序分成20训练、4开发、6已消费评价来源。监督来自作者体表画线；训练入口只读取20/4角色，开发集选checkpoint，六个模型全部结束后才评价。数字目录只是来源代理，**未确认30份扫描对应30名独立患者**。扫描非俯卧、背部已由作者裁取、没有RGB或医学穴位真值。

评价6来源×完整/三种缺失输入×九个方法实例，共216条记录；198成功，18几何方法失败。全部保留。缺失为6 cm空间块移除20%，不是增加随机像素噪声。新模型与原轮廓、对称、沟槽方法同输入比较，不修改几何方法参数。

## 数值结果

指标是同一原生Y位置的横向X差异，与作者画线比较；单位mm。先模型初始化均值、再缺失条件均值、最后扫描等权中位。P95也是扫描内计算再按相同层级汇总，不是全部点池化P95。

| 方法 | 完整 median / P95 | 缺失 median / P95 | 缺失三条件完整来源数 |
|---|---:|---:|---:|
| 普通模型 | 4.57 / 14.59 | 6.99 / 33.60 | 6/6 |
| 缺失增强模型 | **3.36 / 10.15** | **4.15 / 11.83** | 6/6 |
| 沟槽DP | 4.95 / 9.90 | 9.60 / 28.14 | 5/6 |
| 轮廓中心 | 8.49 / 18.00 | 10.13 / 32.06 | 6/6 |
| 对称DP | 37.40 / 69.71 | 不汇总 | 0/6 |

沟槽缺失17/18成功，`candidate_1308 / MISSING_1`失败；对称缺失仅1/18成功，17条失败。不同完整来源数不能直接用于排名。取沟槽三条件完整的**共同五来源、共同Y位置**：沟槽9.60、普通模型7.02、增强模型3.97 mm。明细见[原始结果](RESULTS.json)的`common_positions`。

增强相对普通模型，六个来源的缺失median和P95均改善。缺失输入之间的横向跨度中位10.74→3.80 mm，P95 49.31→19.39 mm。另行测量模型初始化影响：缺失条件的横向跨度16.71→4.18 mm。详见[稳定性分析](STABILITY_ANALYSIS.json)。这些是敏感性指标，不是三维穴位误差。

增强模型缺失情况下约80.6%输出具有3 mm以内的输入点支持；完整曲线输出不代表每个位置都有实测深度支持。

## 图像复查和结论边界

六份完整评价图均实际查看。增强模型总体更接近作者画线，但缺失块与边缘仍有明显局部绕行：1284的MISSING_1上段、1316部分局部偏离等都保留，没有只挑最好图。

本轮支持“缺失块训练有助于这个来源域的体表线提取”。不能据此称已识别脊柱、穴位或俯卧患者的正确解剖中线；小UNet加缺失增强也不是已经成立的论文新架构。后续用冻结模型迁移到既有俯卧数据，结果见[迁移报告](../../../real-scene-2026-10-05/prone-learned-reference-transfer-v1/FINAL_REPORT.md)。
