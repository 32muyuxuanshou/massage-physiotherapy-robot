# 旧结果与修正版的关系

历史结果保留在原目录。V2 建立独立缓存和结果根目录。

| 问题 | 旧实现 | V2 |
|---|---|---|
| 透视射线深度 | 屏幕重心坐标线性插 Z | 逆深度插值，最近正深度交点 |
| 大三角形候选 | 投影半径 99.9 分位搜索，可漏检 | 保守最大半径及逐三角形筛选 |
| 无命中 | NaN 后仅比较剩余误差 | 命中率、全方法共同命中集合同时报告 |
| 初值与深度隔离 | 一些 Txyz/历史 T+Pose 先看全点云 | 新 Official 初值；先划分再优化 |
| Txyz | L1 中 `Txyz(lifted)`移除原限制 | 历史 177.888 mm 限制恢复，raw/applied/fallback 明确 |
| 后背区域 | torso band 与全 Mesh | RGB 后背 ROI + 固定工程后背三角面；另保留旧 torso |
| 模型/算法参数 | 原目录多个变体 | 仅五方法；O2 与 Rigid/D 冻结，不看新结果改权重 |
| 网格保存 | L1 主要保存 CSV；复画需重拟合 | 每方法/种子最终顶点、面、完整参数、变换、索引与配置 |
| “阈值放宽”图 | 实际读旧 fallback 网格 | 不复用该图，图片方法名与缓存文件一一对应 |
| RGB 图 | 相机 XY 正交图部分被当作透视 | 原 RGB + 原 K 的透视光栅；正交/切片单独命名 |
| 矢状切片 | 部分旧图按 Y 筛选 | 真正相机 X 平面与三角面的交线；不称解剖正中线 |
| 质量 | 部分比较会混入全局旋转 | 全局刚性对齐后法向变化代理；边长变化；不声称保证无自交 |

解析三角形上的点，旧算法曾得到 166.67 mm 而非零；这证明评价公式错误，**不表示真人结果统一偏差 166.67 mm**。V2 的同例为零，大三角形例正确命中。

旧测试集 `O+Rigid+D` torso median 汇总约 **3.60 mm**；本地 S107 新后背 median **2.92 mm**不能与它直接比较：区域、受试者数量与初始化/评价合同不同，且正式 V2 尚未执行。完整差异需待新的 20 人结果后逐人、逐种子、同口径对账。

canonical 后背来源文件的旧单位标签存在 mm/cm 历史问题。V2 只使用固定 face ids，核对 int32 C-order faces SHA256；不使用 canonical 数值距离。来源说明明确 raw canonical 单位 cm，因此这里不存在再次将 canonical 坐标错乘进真人评价的路径。

代码保留原 `fit_txyz/sample_points/optimize_pose/fit_rigid/fit_displacement/ray_targets/visible_mask` 函数体，并以 AST digest 校验。`baseline_v1.py` 的历史 CLI **不是正式入口**，其原注释/建议不覆盖冻结合同；正式运行只使用 `run_comparison.py`。
