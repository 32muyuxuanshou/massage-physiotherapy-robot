# Real sensor validation specification V1

A future study must use the target robot RGB-D sensor and freeze intrinsic calibration, depth scale and camera-to-robot calibration. It must characterize depth holes, edge noise, temporal noise, bed/contact conditions and Cheap Txyz sensitivity with repeated static and motion captures. BEHAVE/HuMMan results remain valid within their dataset and calibration domain; they do not establish target-sensor performance. This experiment is not run here.
