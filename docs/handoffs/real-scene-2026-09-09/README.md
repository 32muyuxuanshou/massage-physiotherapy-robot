# 网页端交付：真实场景Mesh微调与批量审查（2026-09-09）

这是当前交付入口，替代9月7日“37点已复核、未训练”的旧状态。目标仍是复杂真实场景的人体表面贴合与固定37工程点定位，工程优先；当前无医学穴位精度或真实毫米精度结论。

## 请先了解这次结论

已下载1280张COCO原图及24个官方COCO MHR分片，匹配641图1110人体；按既有条件筛选为343图427人体，274图345人体训练、69图82人体验证。不是只训练几张图。所有人按原图分组，未证明跨身份独立，COCO可能曾参与SAM预训练。

原权重仅解冻人体与相机两个输出proj，以官方拟合2D/3D关节监督训练10轮，共440次更新、3450次人体曝光。完成全部69图82人的原模型、第2轮、第10轮mesh对照，共246次预测。

**批量看图发现旧bbox-IoU匹配会在多人场景配错COCO人工标注。** 全427条核查后17项明确改配已查看复核，9条训练记录有歧义，不使用新增人工loss。验证集中两图三个人体已修正，全部69图82人仍保留。旧指标只供追溯，以下更正指标为当前结论：

| 人工关节指标 | 原模型 | 第2轮 | 第10轮 |
|---|---:|---:|---:|
|NME，越低越好|0.03520716|0.03524261|0.03544242|
|PCK05，越高越好|0.79130853|0.79232961|0.79303647|

平均NME未改善；逐图配对重采样区间跨零，不能宣称稳定提升。原10轮直接使用MHR拟合目标，错误人工对应不直接进入其loss，但影响了旧人工评估与候选筛选。修正指标的下降不是模型进步。

## 当前正在做什么

修正对应后的可见人工关节监督V2已从官方原权重启动，总10轮；同图片、划分、种子、学习率和参数范围，只增加COCO可见(v=2)人工12身体关节loss。9条歧义记录只计算原拟合loss。交付检查时已到第3轮、累计120次更新，尚未完成，不采用被主动中止的未修正V1。

先检查这项独立监督能否带来收益，再决定目标可见轮廓监督和更多困难场景数据的投入。不会直接把训练loss下降等同mesh表面或37点更准，也不直接用第10轮替换官方模型。
