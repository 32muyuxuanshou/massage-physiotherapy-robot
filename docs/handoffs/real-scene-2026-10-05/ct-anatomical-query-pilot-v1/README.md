# CT解剖查询学习原型V1

目的：在只有外表面输入时，定位由同一次CT逐节椎骨标签定义的体表参考代理。它承接当前MHR表面与查询身份失败的证据，不将穴位标签凭空赋给表面。

[执行合同](PROTOCOL.json) / [实际模型结构](MODEL_ARCHITECTURE.png)。源码含输入准备、三组模型、固定预算训练、完整评价、缓存重算。

服务器：`xuhd@172.18.18.151:436`；目录`/raid5/xuhd/datasets/ct_anatomical_query_pilot_20261005`；环境沿用既有SAM venv，不修改基础依赖。CT读取依赖nibabel隔离在来源目录的deps；模型只读派生输入。

本阶段不运行新SAM/MHR，不接触旧20人的测试点，也不把CT参考称临床穴位。原始CT与checkpoint只留服务器。

九次实际训练、78例全量输出/780缓存/3120有效目标和CPU独立重算完成。参见[完成报告](FINAL_REPORT.md)；模型推理精度仍是CT骨标签代理，未验证俯卧或医学穴位。
