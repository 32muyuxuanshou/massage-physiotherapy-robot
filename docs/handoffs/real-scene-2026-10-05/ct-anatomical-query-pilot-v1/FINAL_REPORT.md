# CT外表面 → 解剖参考查询 V1：完成

**外表面输入能定位CT骨标签代理；有序查询比普通回归好，但误差仍约厘米级，尚未获得俯卧或穴位能力。**本轮不是SAM3D微调，也没有新的Mesh拟合。

## 实际执行

同一份128×128 CT后侧表面高度、有效mask、物理图像平面坐标；不输入CT密度、骨标签、答案或绝对DICOM坐标。目标是C7/T3/T5/T9/L2椎骨标签后侧2%极值的体表投影，**不是棘突下凹陷或穴位**。

102源例先按固定seed42分配角色，再按扫描覆盖/标签资格处理；s1373在训练前发现C7逆序，排除整例并保留原记录。实际51训练、11开发、12新任务测试，4作者val支持。它是项目新分割，不是作者官方benchmark，病例ID不额外称独立患者。

三组网络共享编码器规格、训练预算和输入，三初始化各120轮，九次训练全部完成，checkpoint只按开发结果选择。GLOBAL/HEATMAP约8万参数，ORDERED约30万参数；当前比较不能把所有收益单独归于顺序约束。九次训练单次约4.1–12.0秒，完整图像/评价约103.4秒；复查文件均已保存。

## 完整测试事实

|方法|12例等权X/Z均值/mm|各初始化例均值/mm|比全局回归改善例数|
|---|---:|---|---:|
|训练目标中位位置|56.35|56.35|—|

主指标：每例有效目标均值 → 每例三个初始化中位 → 12例等权均值。所有有效答案都参与；测试四方法的有效目标表面命中率均100%，没有丢掉未命中的困难目标来改善分数。

有序查询相对回归约19.4%改善，4例仍退化；最差例s1350有序查询约34.85mm。有序查询分等级median/P95：C7 14.81/27.73（仅3例）、T3 14.19/31.03、T5 18.30/33.34、T9 18.11/34.54、L2 16.49/38.89mm（9例）。不能把总体结果写成稳定毫米级精度。

固定中位位置是弱基线：不同等级的可见训练例/FOV不同，独立中位可产生顺序不一致。核心比较应看回归/热图，不能用56.35→17.57夸大“解剖学能力”。

## 方法决策

保留有序查询作为**CT来源内的解剖参考候选**，不直接迁移为PressurePose穴位点。下一步只做一次高度/轮廓/扫描尺寸输入消融，确认模型利用了什么；之后接三角面参考绑定和工程规则接口，不继续在这12例上加轮数或试很多网络。

论文仍需统一的RGB-D证据、逐节解剖参考、MHR患者曲面关联以及独立真实俯卧验证。已有query只是普通结构原型；CT到俯卧的姿态与软组织变化没有解决，当前不能承诺MICCAI/顶会创新或临床可用。
