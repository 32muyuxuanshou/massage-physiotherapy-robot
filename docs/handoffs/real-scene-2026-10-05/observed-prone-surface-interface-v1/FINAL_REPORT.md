# 真实观测点云接口：已执行，尚非精度验证

这一步把 **S107 的作者原始观测点云**接到了冻结 V2，再输出缓存患者 Mesh 上的建议参考和规则候选。此前 20 人接口检查用的是从预测 Mesh 采样的点。本轮没有训练，没有重新跑 SAM 或拟合 Mesh，也没有改变旧实验。

## 实际输入与合同

- 原始 `S107_p_select.p`：SHA256 `e3f92851f242c9898803c80dc7ee611f0ac7c5926c08da176a6301c202f59742`，唯一 `p_sel_prn` 为索引 4。
- 原始 RGB 为 880×440；depth 原存储 440×880，沿作者处理链 `rot90` 后由 mm 转 m。点输入来自作者过滤的 **64,946 个 world 点**，经历史冻结变换进入 camera_m；不是预测 Mesh，也不是拟合人体真值。
- 复用修正版实验的相机、RGB 后背 ROI 和种子 0 空间块划分。原 RGB/depth/相机点数组 SHA 与历史记录完全相同，四个 split 数组也逐项完全相同。相机仍为 **近似 pinhole，未经独立毫米级标定**；不能把这个成功接口称新部署精度。
- 固定现有 RigidD/seed0 患者后背网格。四个参考继续是几何 fixture；25 mm 仍是规则检查尺度，不是患者医学 B-cun。
- 观察输入取历史 train 与冻结后背 ROI、两参考沿轴 [-0.4,1.4]／旁开 ±150 mm 的交集。共有 **9,452** 个可用训练点，固定采样 **512** 个，与历史留出点交集为 **0**。
- 冻结四 TRAIN CT、40 步结构检查权重。此权重此前 3/4 来源输给比例先验；这里未升级为有效医学模型。

## 实际结果

同一 Mesh、模型和参考输入，分别执行“512 个 Mesh 采样点”和“512 个作者观测点”。两个分支都生成 3 个建议和 8 个规则候选。

| 建议槽 | 换成观测点后的三维移动 |
|---|---:|
| C7_T1 | 0.999 mm |
| T5 | 0.754 mm |
| T9 | 1.082 mm |

这是**输入来源改变的输出差异**，不是定位误差或改善量；采样坐标也不同，不能把它当严格单因素噪声实验。C7_T1 是现有接口槽名，CT 等级代理不代表标准穴位的棘突下凹陷。

观测分支原始射线修正绝对值 P95 为 **4.527 mm**，只保存而未应用。这是模型输出幅度，不是改善或精度。患者表面保持原样。

缓存重放实际完成：两缓存、6 建议重新解码、16 规则重新投影和面绑定复核通过；不需要权重、不重新推理、不重新拟合。公开图仅展示预测 Mesh／坐标场；原始 RGB 叠图保留在本地私有目录。
