# 注册人体后背对应学习机制 V1：运行前合同

目的：观测表面点的 canonical 身份能否被学习，并能否在局部缺失时比几何近邻/整体点云模型稳定。不是穴位实验，不生成医学或治疗目标。

## 数据与边界

使用作者公开的 FAUST_r/off_2 + corres 非对称 vts。100份注册真实人体衍生网格。每个 vts 是共享5000个参考采样的1-based顶点索引，不是MHR顶点编号，也不是一一无重复排列。模板固定tr_reg_000，绝不按测试表现换模板。

沿DiffusionNet编号划分保留080–099考试，000–059训练、060–079开发。编号块不当已核实受试者身份；研究结果按网格来源统计。SCAPE已下载，只做库存，不混入FAUST训练或宣称跨数据泛化。

模板后背ROI固定：Y=0.10…0.42、|X|<0.18、Z<-0.02、顶点法向Z<-0.30（作者原生坐标）。利用注册对应裁出同一语义区域，这是oracle后背分割的机制实验，不验证自动后背识别。

每个完整网格中心化并除以sqrt(完整网格面积)，输入保留作者预对齐姿态。完整几何用于此归一化，强于真实单相机输入。法向从当前可见点邻域PCA估计。无RGB、相机、原始depth、MHR或医生真值。

作者衍生坐标物理单位未充分核实，不报mm；误差为模板单位面积坐标欧氏距离×100（%sqrt(template area)），不是测地误差或人体位置毫米误差。原始及含几何/标签的缓存/训练权重仅服务器，不重发Git；限非商业学术研究，产品训练另需许可。

## 对照

1. TEMPLATE_NN：当前输入点到固定模板后背最近邻，几何基线。
2. POINT_GLOBAL：XYZ/当前估计法向→PointNet式局部编码+全局max→canonical XYZ。
3. PRIOR_GLOBAL：增加模板近邻XYZ/偏移，并学习相对模板近邻的残差；检验先验条件化。
4. PRIOR_LOCAL：在PRIOR_GLOBAL上增加12近邻的边特征聚合；检验局部结构。相同坐标损失，不新增不确定性/gating。

三学习模型×初始化0/1/2，各1200 optimizer steps、batch8、256点、Adam lr0.001、SmoothL1 beta0.02。开发集每200步评价，仅开发选checkpoint。所有模型相同数据和损失；固定种子、首次运行不看考试调参数。

每份源网格×FULL / PARTIAL_BAND / NOISY_PARTIAL×扰动seed0/1/2。PARTIAL按输入Y分位范围随机移除20%宽纵向带；NOISY_PARTIAL加单位面积坐标std0.002高斯噪声。为程序模拟遮挡/噪声，非真实sensor。训练额外刚体小旋转（±10°）同样用于全部学习方法；法向/输入/近邻随之变换，目标身份保持不变。

## 评价

观测点canonical距离median/P95；27个固定模板工程query中，当前可见的query做检索位置身份错误（单位面积模板距离）及对应当前网格位置距离；不可见query仅计覆盖，不硬做伪completion。27query预先以模板后背XY 9×3规则网格最近已有参考样本选定，重复合并，不以结果选择。

所有方法共用相同观测索引/目标/噪声。每方法先初始化取均值，再扰动seed取均值，再逐源/条件比较；最后20来源取中位，并保留逐源失败。不把点数量当独立样本，不称20患者。

通过标准：完成可复查的机制对照并决定对应模型是否值得继续，不强制新模型胜出。不以此批准临床应用或宣称顶会创新已成立。后续若有增益，需加公开强基线、独立数据/俯卧/MHR对应；否则转向更适合局部身份的表示。
