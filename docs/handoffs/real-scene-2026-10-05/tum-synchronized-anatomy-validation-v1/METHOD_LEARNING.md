# 本轮论文学习如何影响方法

本轮读取主文方法、数据、实验和限制；BODIESReg的初始化及配准图也已实际查看。以下是方法取舍，不是接收预测。

|原始工作|可取的部分|我们不能直接照搬的部分|
|---|---|---|
|[TUM同步CT/背形论文，PLOS One 2026](https://doi.org/10.1371/journal.pone.0353213)|用同次CT导出皮肤与骨骼，减少跨姿态表面/影像对应问题；因此实际下载17病例并完成本轮冻结外部考试。|作者老年皮肤松弛群体中10/17病例的传统C7/骨盆参考困难，采用适配坐标。不能把CT坐标代理或来源manual字段直接称WHO穴位标注。CT扫描姿态仍不等于俯卧。|
|[PointNet++骨盆体表landmark流水线，Sensors 2026](https://doi.org/10.3390/s26061760)|ROI检测→姿态对齐→landmark回归，受试者划分而不是随机扫描划分；临床触诊标记提供明确监督。107人1806扫描，22人考试，点误差中位11.25 mm。|主要站立/前屈，非俯卧背部穴位；作者数据需合理请求，未实际获得。不能把少量CT代理与该临床触诊成绩直接比较。多模块拼接已有先例，单独增加landmark head不够新。|
|[BODIESReg，arXiv 2607.15463](https://arxiv.org/abs/2607.15463)|投影pose→VPoser初始化→表面配准；对复杂姿态先解决初始化，再讨论拟合。提供交互参考机制与批处理。|是2026预印本。82.9%/100%成功率与成功样本<10 mm表面距离不等于解剖点准确率。论文明确缺少独立解剖真值、仰卧接触导致变形；不能把模板对应当医生标注。|

因此最终候选应把“RGB-D局部真实几何”“全身MHR上下文”“带身份的稀疏参考”联合到同一患者表面坐标中。规则层保持透明，不直接学习黑箱穴位。必须同时检查几何距离与等级位置；比例先验和已有配准/landmark流水线都要成为基线。

具体推进顺序：先把两参考比例模块接到实际MHR缓存，输出**可修改的建议参考**，逐点保留来源和与输入参考的区别；不要默认补全为真值。随后设计跨来源参考条件化表示的训练合同，若无法击败比例基线，就继续作为工程交互方案，不包装为新架构贡献。
