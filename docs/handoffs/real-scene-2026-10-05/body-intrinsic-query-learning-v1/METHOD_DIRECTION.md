# 走向最终工程与论文方法

这次改变的是**学习模块负责什么**：不让网络只把任意点贴到曲面，而是给定模板上的目标位置，学习它应该对应到当前观测的哪一处。Mesh表面拟合仍保留独立基线，目标身份定位使用自己的监督与评价。

## 最终使用路径

1. 实测K的真实RGB-D。RGB→官方SAM3D/MHR，得到全身姿态/形状与模板对应；Depth→当前可见后背点云。
2. 保留Official、Txyz、T+Pose及Rigid/D工程对照；已有后背表面校正负责测量几何，不自动证明穴位身份。
3. 模板query由atlas/参考规则给出。身体先验给出粗位置及方向；局部曲面特征与未来图像特征判断当前观测中对应的位置。
4. 在患者Mesh绑定xyz、face、bary、normal，或由可靠参考建立规则坐标。骨度分寸/椎体水平不能由表面距离直接推断。
5. 最后才验证医学位置、相机→机器人变换与接触。当前输出仍ENG，不将代理当医生真值。

当前实际实现第3步的几何/位置双路学习原型和第4步工程接口；**尚无RGB语义融合、自动医学标志或临床评价**。MHR推理当前冻结，不宣称整套新RGB-D模型已经训练完成。

## 为什么要这次结构对照

- 表面贴合：既有Rigid+D可以改善局部测量距离，但不能保证模板点不滑动。
- 全局结构：纯几何近邻缺少姿态/身份参照；早期MHR粗框架NN也会偏约88mm相对拓扑点。
- 局部身份：简单共享PointNet跨SCAPE明显退化；冻结DiffusionNet局部输入同样失败，完整身体参考更好。

因此本轮比较BODY、INTRINSIC、DUAL，直接检验两类信息是否互补。若双路没有独立增益，不能为了论文保留它；若局部训练有效，再推进MHR/俯卧与图像语义，而不是继续修同一20人的bounds。

## 论文贡献当前能说到哪里

研究张力明确：**有准确表面并不意味着目标身份正确；局部背部外形相似，全身对应先验又不适应局部边界。** 已有真实注册数据与俯卧接口使问题可测。

可形成的贡献候选是：整体身体先验与局部测量之间的对应机制、能够保留目标身份的表面更新、具有独立几何/身份参照的床上验证。前两项需要模型实验证明，第三项仍缺独立俯卧裸背/解剖参考。普通PointNet、concat、投影或后处理本身都不足以支撑强论文。

FAUST/SCAPE注册是作者拟合对应，不是临床身份真值；oracle ROI及全身体中心尺度也是更强输入。20 PressurePose属于已消费、穿衣、近似相机、同源空间留出；PCdare线是作者体表画线而非已知椎体。不能把这些不同证据相加写成高精度穴位定位。

## 本轮之后怎样走

- 若双路跨库和局部输入有稳定增益：先接同一MHR query接口，检查是否还出现17–19cm迁移错位，再研究RGB与身体先验提供的增量。
- 若仅身体分支够用：采用简单结构，说明几何分支当前无价值，不硬堆模块。
- 若全部失败：停止这一类几何学习，转向可观测解剖/图像参考来源；不继续在SCAPE考试上调超参数。

工程保留Topo＋surface fit；学习模型只有证据通过后才升级。顶会目标需要更大的独立身份/临床验证和与强方法的公平比较，当前不预测接受概率。
