# 俯卧点位工作台 V1

本阶段完成工程闭环与人工复核接口，不再训练、修改相机或拟合Mesh。使用前轮20俯卧、3训练点划分、Rigid/RigidD缓存与8个ENG模板query，默认仍TOPOLOGY。

新增实验BODY_CHART_NN与最新BODY_QUERY三个开发选checkpoint。双路与纯几何学习在注册跨库中未胜出，不接入工程默认，也不以俯卧结果反调模型。

源模板及目标输入直接沿用上一MHR查询接口缓存和训练点索引。新BODY网络使用patch分位坐标＋法向；连续source query描述子按三角角点bary插值。匹配后采用原严格后背面投影，输出xyz/face/bary/normal/原点索引。原Topology直接同face/bary传播。预期600绑定、4800点，实际缓存后重算。

交付全部20人对照图、缓存与JSON。离线工作台以固定S104/input0/RigidD作默认示例，不按结果挑：显示原图、预测后背面与ENG点；用户/后续医生可在原图点击参考点，射线与实际预测后背三角面交点返回绑定并保存复核JSON。该标记只是本预测面上的人工参考，不自动是医学真值。

RGB原图仅本地/服务器工作台，不进公共Git。工作台使用历史重建K，不能当新相机标定；无robot release。公开代码、派生MHR几何/目标缓存、完整指标与可展示图进入Git。

对照只报告稳定性、贴面距离和与Topology位置差；没有独立解剖GT，不报告穴位精度。阶段结束后以事实形成下一项主方法/数据计划，不在20人上反复调整查询约束。
