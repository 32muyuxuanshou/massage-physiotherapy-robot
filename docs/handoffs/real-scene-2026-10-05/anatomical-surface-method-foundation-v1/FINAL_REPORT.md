# 本轮事实：扩大数据与联合方法原型

**已完成方法与数据流水线的基础；没有取得新模型的泛化成绩。** 方向从继续调51例小网络，转向更大规模的皮肤—骨骼监督和可选参考输入的解剖坐标场。现役工程几何与规则基线保留。

## 1. 数据实际取得到什么程度

官方[TotalSegmentator V3](https://zenodo.org/records/22688904)于2026-09-10发布，CC BY4.0，完整ZIP为37,415,622,057字节，作者MD5为`0728beea76475e92cdb3160e228265d1`。

本轮从ZIP实际读取目录和`meta.csv`，不是照网页标题计数：232,682项、**1,939份CT图像，1,830 train / 109 test**。公共元数据没有患者ID，所以不声称1,939位独立患者。作者说修正了椎体等级混淆，但每份是否适合后背监督仍要按来源资格处理。

来源角色在新模型结果前冻结：

| 角色 | CT图像数，资格筛查前 |
|---|---:|
| 成人TRAIN | 1,393 |
| 成人DEVELOPMENT | 125 |
| 尚未使用的作者成人test图像 | 88 |
| 旧已消费dev/test/author-val | 14 / 14 / 4 |
| 小于18岁，仅支持来源 | 286 |
| 年龄缺失，仅支持来源 | 15 |

旧102个ID全部出现在新包，旧角色保留。不会把修订版ID重命名成“新患者”。

**最后确认下载量为33,964,150,846 / 37,415,622,057字节**，见带UTC时间的`DOWNLOAD_PROGRESS.json`。其后服务器先有进程磁盘等待，再有SSH命令/握手失败；完整下载完成与作者MD5尚无法核实。已启动下载后成人来源处理链，不将“已启动”写成“已完成”。

## 2. 18等级来源构造器实际运行

保留之前CT-only皮肤抽取程序的原字节，新的包装器抽取C7、T1–T12、L1–L5。后侧2%椎骨体素均值投到皮肤，形成等级代理；在这些代理之间插值得到纵向/横向坐标监督。

四份旧TRAIN：s0011、s0344、s0358、s0511，**4/4资格通过，64/72等级有效**，其余边缘/缺失等级留掩码。保存32,768个皮肤点，16,473个解剖监督点。CPU独立重算最大坐标差`5.90e-8`，四份来源图均实际查看，保留扫描裁切、皮肤接触形状和缺失。

来源处理第一次受系统磁盘等待影响，显式使用任务目录的临时/Matplotlib缓存后，两进程正常路径完成。未改源CT或骨标签。它们是v2旧训练来源，不冒充已经完成的V3大队列。

**这些是CT等级代理，不是临床棘突下凹陷或穴位真值；CT皮肤形态也不是已认证的俯卧皮肤。**

## 3. 训练路径实际运行

原型使用局部位置注意力＋整体特征＋有类型参考token，共126,917参数，输出表面位移和解剖坐标。

在服务器GPU0，四份旧TRAIN、80步的实际路径检查完成：

| 无量纲loss | 随机初始化 | 80步后 |
|---|---:|---:|
| 表面 | .08920 | .009329 |
| 解剖坐标 | .29075 | .058681 |
| 合计 | .37995 | .068010 |

保存了1,024个查询对应的输入/输出、索引和参数身份；CPU直接从缓存重算通过。但**零表面修正的loss是.008775，比训练后的.009329更好**。所以这里只能说两个分支能训练，不能说表面修正有效。不是测试集精度、不是原生RGB-D去噪，不将随机初始化对照当工程收益。

大规模代码另已完成三条真实派生缓存的CPU正常路径：GLOBAL_ANATOMY、LOCAL_ANATOMY、LOCAL_JOINT，前向、反向、一步optimizer、18等级解码及排除输入参考的评价函数通过。活跃梯度参数分别113,986、126,722、126,917；虽注册参数相同，**不称有效容量完全一致**。

本地CPU为PyTorch2.4.1、服务器原型为2.4.0+cu121；CPU检查不是GPU正式训练的精确复现。服务器后续一次`--check-only`尝试未取回结果，不算通过。

## 4. 已实现、尚未执行的正式源域比较

- 完整成人来源处理；完整数据未结束前不启动大规模训练。
- 三模型×种子0/1/2，60轮；开发集有参考/无参考解剖loss等权选择checkpoint，不看test。
- 以TRAIN拟合两参考比例先验，以及无参考的总体先验；不是按test病例拟合。
- 同一8192点候选皮肤、同一观测/几何查询采样、相同参考噪声；T3/L2输入目标从方法分数中排除。
- 主对照为两参考共同CT图像；5mm参考扰动与无参考另列；保留逐等级和逐图像结果。
- 汇总顺序：等级均值→每CT图像的三seed中位数→图像等权中位数/均值。没有患者ID，不能偷换成患者等权。

代码和合同都在包内，**上述大规模训练/考试尚未运行**。几何任务是已声明的CT皮肤扰动恢复，不能转述为独立sensor验证。当前模型没有SAM/MHR/RGB输入，真实MHR接入还需实现和验证。

## 5. 判断与下一步

这个方向值得验证，但“两个head＋Point Transformer”不是足够的创新。已有表面到内部解剖、全局隐式解剖和稀疏marker模型，见`LITERATURE_LEARNING.md`。候选增量应是：局部观测和少量参考下，个体解剖坐标是否比比例先验可靠，并能落到最终患者表面目标。

继续顺序是完成V3校验与资格→大规模源域比较→跨来源和真实MHR接口。若联合表面分支没有收益，保留可靠几何基线；若解剖场没有超过先验，也不将其包装成论文主方法。最终仍需校准俯卧RGB-D与独立医学目标验证，当前不输出临床准确率。
