# 后续真人核验怎样接入

本流程为准备项，当前没有新增志愿者、临床标注或部署相机。

1. 先冻结模型、几何方法、规则输入和待评价八个目标；给每个输入采集独立ID。模型只能读无参考标记的原始输入，先保存预测与hash。
2. 独立确定真实体表目标及所用参考方法，保留标注者和重复，不把AI/模板/CT proxy作为医生真值。左右按患者身体定义，不能靠图像左右命名。
3. 参考位置的3D来自独立传感器观测。若用体表标记的另一帧取得标签，须保存它到原输入的独立RGB-D注册变换与残差；不能用预测Mesh拟合该变换。人体或皮肤运动没有得到解释时，该帧不能支撑精度结论。
4. 对齐彩色的深度须明确校正像素域、轴向Z、单位、内参和外参来源。`export_observed_reference.py`只做这个已知合同下的反投影；不负责从未知相机参数生成可信标定。
5. `compare_observed_reference.py`把预测与每个参考逐一比较。模型误差、参考一致性、相机/配准残差分开保留；不能用医生一致性替代模型误差，也不能把其均值包装成无误差真值。
6. 同一批目标分别比较固定拓扑、比例先验/规则与来源训练后的新模型。标注及测量人员不以当前模型建议为参照，避免参考受预测诱导。按患者汇总，所有失败和缺失留清单；精度容许标准须在结果前按工程需求明确，目前未获实际设备支持，故不随意宣布5mm合格线。

CT等级代理、骨度参考、标准穴位和传感器测量是四种不同信息。模型坐标场可以给出候选，医学参考核验与机器人坐标精度依然分别需要证据；本接口不把流程跑通等同于已经能治疗。
