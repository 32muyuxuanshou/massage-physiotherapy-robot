# 解剖参考来源与使用边界

作者来源：[TotalSegmentator小包v2.0.1](https://zenodo.org/records/10047263)，Jakob Wasserthal / University Hospital Basel，许可CC BY4.0。原包3,244,617,817 bytes，作者MD5为`6b5524af4b15e6ba06ef2d700c0c73e0`。实际下载/校验结果以DOWNLOAD_RESULT.json为准；原始CT留服务器。

元数据从ZIP64中央目录与实际meta.csv读出：102 IDs，98 train/4 val；不是102新的俯卧RGB-D病人。官方study_type不能保证全部椎体有标签，s0250的颈胸目标实际缺失。不同扫描FOV和边界接触全部报告。

抽取外表面仅用CT HU，不使用骨标签来生成模型输入。逐骨标签仅作参考代理目标；标签中心与后侧极值是两个不同的定义，均不是WHO规定的棘突下凹陷。模型训练在另一个冻结合同中；本目录只给源资格。

CT标签标注链与局限依据：[作者论文](https://doi.org/10.1148/ryai.230024)，辅助模型初始分割经医生复核，仍有相邻椎骨/肋骨误标等风险。它比人工猜测MHR椎体比例有独立解剖依据，但不是绝对GT；CT外表面与真实俯卧软组织/接触状态有域差异。

派生图像与几何若用于论文请注明来源、许可和本项目HU/形态学处理；不可把处理后的体表点称作者医学穴位标注。
