# 实际完成与结论

当前完成的是**可训练的方法原型和Mesh→规则接口**。全量训练、真人解剖位置和穴位准确率尚未完成，现役工程几何/两参考比例基线不被替换。

## 为什么推进V2

V1把参考点送入注意力，但没有确保输出坐标遵守参考。其几何目标还要求从含三维扰动的查询恢复原点身份，其中切向扰动无法仅靠贴面决定。V2保留原点注意力编码器，明确两参考局部物理坐标、硬参考残差提升和沿已知射线的几何目标。

这不是声称两项操作各自新颖。硬约束、局部注意力和语义参考都有已有工作；论文价值仍须来自正确问题定义、有效整体方法和独立证据。

## 已运行

1. 四个旧TRAIN来源`s0011/s0344/s0358/s0511`，三方法各40步CPU训练；没有读正式test。SOFT_ANATOMY/HARD_ANATOMY/HARD_JOINT均完成前向、反向及缓存。
2. 硬参考坐标最大误差`3.61e-18`（无单位），软参考`0.01170`。这验证代数合同，**不是医学定位误差**。
3. 相同输入作任意刚体变化并从mm转m后，局部输入最大差`2.91e-8`。这是坐标处理检查，不证明跨姿态人体形变能力。
4. 联合分支训练检查的射线误差中位6.48→6.25mm，属于四TRAIN例模拟径向噪声，不能当独立传感器改善。解剖单任务的未训练表面头没有应用。
5. 四例正式评价器正常运行并缓存重算。结构权重XYZ代理误差/比例先验分别是：9.93/5.67、6.97/8.04、7.73/4.36、12.77/3.82mm，**3/4例仍输先验**。仅列为检查事实，不调小样本轮数去追分。
6. 20实际既有Mesh接入：60建议、160规则、全部20图；220面绑定缓存重算最大差`2.29e-16m`。输入参考是几何fixture，观察点由Mesh采样，非医生标注或新RGB-D输入。射线分支没有改动现役患者Mesh。

全量缓存的坐标图诊断还发现：27371个可比较ROI面中32个相对于输入平面图发生取向反转，60建议中10个没有精确的坐标图交点。没有过滤这些面或建议，也没有追着它们调模型。硬参考精确成立不意味着坐标图处处可逆，更不意味着解剖位置正确；本原型不声称微分同胚保证。

建议点是CT等级代理槽，C7_T1名称只是现有规则接口槽名；CT C7皮肤投影不等于棘突下凹陷。规则继续使用原显式B-cun输入和冻结投影模块，不把25mm fixture称个体医学尺度。

## 正式实验准备

代码已实现九个来源训练、0/5mm参考误差条件、同候选皮肤点的比例先验/软参考/硬参考/联合模型评价与三初始化汇总。沿用V1在新模型结果之前冻结的V3 image角色，不使用旧已消费DEV/TEST，也不声称患者级独立。

输入固定为两参考与局部物理框架。候选ROI只取输入参考定义的沿轴[-0.4,1.4]、旁开±150mm；所有方法共用。CT代理等级和查询皮肤不被用来给方法单独挑范围。T3/L2不进入误差分数，表面射线查询与观察索引交集为零。

5mm参考条件是每轴标准差5mm的各向同性高斯扰动，不是总位移不超过5mm。

V2是径向点云扰动预训练，尚未验证每个CT源点为相机射线的first hit；不能称完整RGB-D合成或原生传感器实验。源内解剖XYZ、X/Z和射线残差分开报告，不与临床穴位误差混用。
