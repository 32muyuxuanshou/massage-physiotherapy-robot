# R5.2 零训练求解器因子对照

采纳同起点几何对照，不采纳“终极上限”“零算力”“一定消灭fallback”或“所有射线共线”的结论。每个点的差向量沿各自射线，整组射线并不共线；曲面深度梯度和RGB仍可能提供横向信息。

只用218已授权资源与原缓存。固定Full Last三seed、原Body和各自历史Coarse。400 Native VAL＋192/40 HuMMan＋270 BEHAVE，每seed902帧。没有新训练、扩大数据或模型架构改动。

冻结18方法：旧Official+Txyz、Coarse、原Fine三参考；同16384 Anchor历史算子1/2/3/6步；256全部/初始可见子集；可见256 Mesh→Obs方向；相同密集对应的截断均值/点面LS/LS加旧方向衰减；同缓存Depth格点下可见256的同像素投影残差与三维NN一步、均值/点面算子控制。投影额外分原Fine的Query射线赋值、与实际所采像素XYZ两档，避免把像素量化的射线差别归给NN。完整定义在EXPERIMENT.json。

控制对应方式时，投影与NN必须使用同一份Depth格点输入；不能给NN历史raw5000点、给投影另一份预处理Depth后将差异全归给对应方式。历史raw5000系列单独对账，不与格点系列混称同输入。

所有新增几何更新保留每轴50mm限制、总修正177.888mm限制；上限相对于各自起点。Coarse方法fallback回Coarse，并单独记录从Official到最终的总移动。原Fine参考保持原样，不额外套历史步长限制。可见子集锁初始Coarse，不在迭代中暗改筛选。点面LS使用固定SVD cutoff1e-6，方向衰减作为单独变量。

先验证合成平移例与点面退化例，再复算少量Official+Txyz与历史raw/applied translation、fallback、指标。通过后生成全部方法位姿，再独立打开B/真值评价；任一实际不一致先定位，不放宽合同。逐人P95、fallback、原11失败帧与p001195/p001196、每seed都交付。真实域是已消费开发集，不将最佳诊断分支事后定义为新模型。
