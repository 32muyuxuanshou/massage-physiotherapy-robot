# 无部署相机时的俯卧背部路线

后续执行已完成，见[实际结果](../../handoffs/real-scene-2026-10-03/prone-back-point-validation-v1/FINAL_REPORT.md)。以下为执行前记录，不作为当前任务状态；新结果显示atlas语义问题和独立机位D增益不足，下一步先修工程参考与验证条件。

日期：2026-10-03。状态：替代方案已核查并记录，公开数据取得与结构审计已完成；本文件中的点位传播、跨相机 D 实验和二维语义对照尚未执行。

详细实施顺序、数量、评价与决策条件以[详细计划 V1](DETAILED_EXECUTION_PLAN_V1.md)为准；本文件保留为概览。

## 目标与当前约束

目标仍为真实俯卧 RGB-D → 患者背部表面 → 个体参考与穴位规则 → 三维目标。当前没有部署相机，取消将自采作为下一阶段启动前提；使用真实公开数据推进算法和对应验证。保留最终部署相机标定与机器人坐标验收任务。

保留 2026-10-03 已完成五组基线、20 人角色、种子、缓存与结果；不覆盖历史输出，不以新数据调参后回写历史结果。不承诺未来设备取得相同数值精度。

## 1. 立即可做：现有缓存的点位传播与形变诊断

- 复用 PressurePose 已完成的 20 人 × 5 方法 × 3 种子缓存，无需新推理或拟合。
- 核对既有工程 atlas 点的 MHR LOD、faces 身份、face/barycentric、左右与单位，冻结本阶段点集。
- 每种方法输出同一组点的 xyz、normal、RGB 投影、有效观测支持；保留全部 60 个人物—种子对照页。
- 对 Rigid→Rigid+D 位移作法向/切向分解，参考方向来自 Rigid 表面；报告局部边长、面面积与方向变化。
- 上述分解是形变位移诊断，不是穴位误差；同拓扑传播与 Mesh 插值规则之间的分歧也不是准确率。
- 原图可见标志只作独立视觉参考。衣物遮挡或不能辨认的椎体水平不填写真值。

## 2. 外部几何证据：BEHAVE 标定 RGB-D

- 先核查已有服务器数据、冻结 cohort、各 Date 标定、四机位原始输入与后背可见覆盖，完成运行规范后再执行。
- K0 输入/优化，K1/K2/K3 仅评价；使用各 sequence 的正确标定，统一畸变合同与评价点。
- 新实验单独比较 Rigid 与 Rigid+D，保留 Official/Txyz 等已有对照；维持当前 D 设置，记录完整优化点与输出。
- 后背有效覆盖按参考数据预先确定并报告，不根据方法残差选择视角或样本。
- 主证据为独立机位 sensor points → posterior surface；person_fit.ply 只作 fitted reference。
- 已被历史分析使用的人物仍称已消费工程验证 cohort。BEHAVE 不是俯卧裸背穴位数据，不据它单独声称部署域或医学精度。

## 3. 二维语义证据：DMD-BAK

- 实际核查已发现：当前 V2 下载只有作者整改声明，没有图像；历史 V1 本轮取得 205 组，存在尺寸不一致、越界点、重复图与点类差异，暂不接入正式训练或评价。详见[数据取得与审计](../../handoffs/real-scene-2026-10-03/back-data-acquisition-v1/README.md)。
- 历史图片仅供标签格式和视觉审计，先核实点位定义、受试者身份、体位与图中标记。已人工查看的 37 张未确认床上俯卧，不能按俯卧语义验证集使用。
- 对可匹配的点类，比较拓扑传播与独立图像参考＋规则的二维投影；报告相机/尺度未知带来的限制。
- Mesh 插值生成的代理点不得作独立标签。图上标记可能泄露定位答案，带标记评价须单独说明。
- 没有原始校准 depth 时，只报告二维指标，不使用预测深度伪造毫米真值，不与 PressurePose 样本拼接成 RGB-D 标签。
- 二维通过后，才决定是否训练参考点或对应模块；本计划不启动训练。

## 4. 新增支持数据：PCdare 真实背部扫描

- 已取得固定 commit 的 2,250 个选定文件；504 个 PLY 含 324 个非 Output 路径文件和 180 个派生文件，文件数不等于人数。
- 先绑定扫描与对应标记/参考线 JSON，并核实逐文件单位；源代码包含 m/mm 和旧版兼容分支，暂保留 native 坐标。
- 用于真实背部表面与对应开发；不代替俯卧 RGB-D，不把影像脊柱线或标记自动当作体表穴位真值。

## 执行优先级与决策

先完成缓存传播诊断，同时核查 BEHAVE 运行资产与 PCdare 对应关系；DMD 历史标签保持单独审计。跨相机结果和二维结果分别统计，不把不同任务的毫米/像素指标混成单一成功分数。

若几何改善但语义位置仍偏，下一阶段研究个体对应；若标定可靠的独立机位几何退化，先修正几何方法；若两者稳定，再推进规则和机器人接口。规则准确性最终需独立穴位参考，设备精度最终需真实设备验收。
