## 1. 目标、下一项大任务与整体流程

最终工程目标：真实俯卧患者的 RGB-D → 背部表面 → 个体化工程穴位位置/法向 → 后续机器人坐标接口。研究目标：解释并解决“表面贴近观测，但体表目标仍可能沿表面错位”的问题，形成有独立证据支持的方法贡献。

下一项大任务是完成一轮**表面几何与点位对应分开的验证**。它不依赖部署相机，也不以新增网络或更低拟合残差为完成条件。

当前工程链按以下顺序准备：

```text
公开真实 RGB-D + 已核验的坐标合同
    ↓
冻结 Official SAM3D / MHR 初值
    ↓
冻结 Rigid + D 工程表面基线
    ↓
固定拓扑传播 T0
或 独立参考信息 + 定位规则 T1
    ↓
xyz / face_id / barycentric / normal / 观测支持与来源状态
    ↓
几何与对应分别评价，全量图像复查
    ↓
确定下一阶段投入：标定、表面模型、还是个体对应
```

机器人真实坐标精度、患者解剖穴位精度和治疗控制尚未验收。现在先完成离线定位与数据接口，后续设备到位再接入标定和控制。

## 4. P0：单位、拓扑和来源核对

**回答：旧工程点能否合法传播到当前 300 个 Mesh？**

逐项实施：

- 重新打开 canonical `mhr_rest_vertices.npy`、faces、posterior mask、工程 atlas JSON，以及当前缓存的实际 faces，核对 LOD、顶点数量、面顺序和三角面方向。
- faces 按相同 little-endian int32、C-order 计算统一哈希，同时做数组逐项比较。旧 atlas 哈希为 `f6748e...`，新缓存记录 `0e47f5...`；已读代码显示新缓存使用 int64 哈希，而历史合同使用 int32。不能直接据这两个字符串判定拓扑改变。
- 核实 canonical 原始坐标是否为 raw MHR cm；若确认，canonical→mm 使用 ×10，预测缓存 m→mm 使用 ×1000。禁止用旧字段名 `canonical_xyz_mm` 自行推断真实单位。
- 旧 `run_rule_engine_sanity.py` 当前仍将 canonical 写为 mm、倍率 1，需在独立修正版中更正相关报告/汇总。旧 atlas 数值也从实际顶点与 barycentric 重算，保留旧文件。
- 单位更正不改变已有 face/barycentric；如果发现左右、参考方向或定位种子本身有问题，单列为 atlas 语义问题，不能以“单位修复”名义换点。
- 检查工程点是否在 posterior mask 内、是否落在边界，核对左右。GV14 等若超出固定后背评价区域，照常保留并标 `OUTSIDE_POSTERIOR_EVAL_REGION`，不扩大评价 mask 来容纳点。
- 检查 barycentric 非负/和为 1；验证由实际三角面插值恢复 xyz，Rigid 变换与点位传播一致。

先用 S104/S107/S165/S187 的 seed 0 检查数据流，再扫全部缓存。这里只读缓存，不重新跑 SAM。

交付：`POINT_ASSET_AUDIT.json`、`UNIT_RECONCILIATION.md`、修正版 atlas、统一 faces 身份、逐点 inside/outside 与左右记录。文件名是拟新增输出，当前没有声称已存在。

完成条件：拓扑/面顺序确认；单位证据明确；工程点插值与刚体变换主路径可复算。若拓扑真的不同，先查资产来源；不直接最近点重绑定以掩盖差异。

## 5. P1：300 个缓存 Mesh 的工程点传播与形变诊断

**回答：D 把表面贴近点云时，工程目标沿表面移动了多少，局部形状是否保持？**

首轮固定当前 8 个点：GV14、GV4，以及左右 BL13/BL15/BL18。它们均带 `ENGINEERING_PROXY_ONLY` 来源标记；本轮不扩大到 DMD37。之后扩大点集须有独立版本与来源核对。

对 20 人 × 5 方法 × 3 seeds，传播同一 atlas：

`p = b0·v[f0] + b1·v[f1] + b2·v[f2]`

预计产生 **2,400 条人物—方法—种子—点记录**；这是从缓存计算，不是 2,400 次模型推理。每条至少保存 xyz（m/mm）、face_id、barycentric、三角面法向、RGB 投影、inside/outside posterior、源网格身份和观测支持。

Rigid→Rigid+D 的诊断以 Rigid 三角面法向 n_R 为参考：

```text
δ = p_D − p_R
δ_normal = (δ · n_R) n_R
δ_tangent = δ − δ_normal
```

这里衡量方法之间的移动，不叫穴位误差。若未来有独立目标参考，才另算目标误差，并使用独立参考法向分解。

同时记录：目标三角面及一环邻域的边长/面积变化、法向角变化、退化面、RGB 投影移动、训练点与留出点对目标附近的支持。法向变化不直接等同于自交；检测到退化面时保留失败状态。

不根据留出支持再调 D 或 atlas。参数和图像错位的相关性只作描述，不由它直接推出临床可用结论。

可视化固定为 60 页（每个人物—seed 一页），每页包括原 RGB、五方法叠图、8 点编号、Rigid→D 移动、侧视图及局部质量。全部提供逐图索引，明确颜色含义，不用 GOOD/BAD 标题暗示医学合格。

汇总：先对同一人物/点/方法的 seeds 求算术平均，再列每个人，最后人物等权中位数；每个点单列。个人内点级统计与跨人统计分开。

交付：`PROPAGATED_POINTS.jsonl`、`PER_POINT_DIAGNOSTICS.csv`、`PER_SUBJECT_SUMMARY.csv`、60 页图、`CACHE_SOURCE_MANIFEST.json` 和完整失败列表。

完成条件：300/300 Mesh 来源完整、2,400/2,400 点有输出或明确失败状态，全部图能从缓存重画，读源文件前后身份不变。没有真人点位参考时，本阶段结论止于传播与形变诊断。

## 6. P2：BEHAVE 的 Rigid+D 跨机位验证

**回答：D 的局部拟合增益能否在没有参与优化的真实相机上保留？**

复用已消费的 5 人 45 帧 frozen cohort，保持原 timestamps。K0 是 RGB/深度输入和优化来源；K1/K2/K3 只评价。以当前官方数据工具为标定对照，其外参读取与 sensor 流程见 [BEHAVE 官方仓库](https://github.com/xiexh20/behave-dataset)。

开工先做资产和观察范围清点：

- 确认 Date03/Date05/Date06 的相应标定、四相机文件、person mask、有效 depth。
- 同时冻结每帧 K0 是否看得到后背，以及 K1/K2/K3 的可见后背 ROI；根据原始 RGB 和参考资产记录衣物/物体遮挡。背包等遮挡面不当成可见背部传感器参考。
- 45 帧全体均留在清单。无可评价后背的相机标状态及点数，不填 0 mm；报告实际评价人数、帧数、机位覆盖与缺失原因。
- 按日期与官方 transform 做数值对照，审计跨机位点云对应；渲染必须与畸变/undistortion 合同一致。

方法保持五组：Official、Txyz、Txyz+Pose、Rigid、Rigid+D。主新增配对是 Rigid 与 Rigid+D；其余组用于解释全局平移/姿态起点。沿用当前冻结 D 配置，不增加后背专用约束并仍称同一方法。

每帧共享同一 Official 初值、原 RGB/K/bbox、相同 held-out 点与 posterior faces。先核实历史缓存是否含完整未拟合 MHR 参数；若缺失，则按冻结输入重新生成 Official 一次并记录与历史的差异，所有分支共享它。

正式前只用已消费 Sub01 做模型 smoke。fresh 一词不再用于本轮 5 人。有效性的纯数据 QA 可覆盖 45 帧；看到新模型结果后不改变样本或阈值。

初始固定 seed 0；若复用的某执行路径含无法消除的随机采样，须在 full 前明确追加 seeds 的合同与数量。seed 0 计划规模为 **45×5=225 条帧—方法记录、最多 675 条机位—方法记录**，同时记录有效评价数；不把重复 seeds 计为新人物。

主指标：held-out posterior sensor points → predicted posterior triangles 的 median/P95 和固定 50 mm coverage，附完整点数。射线同时报告命中率与共同命中；单向点→面距离辅以可见区域覆盖/轮廓，避免大或偏移表面获得小残差。

对 median/P95/coverage 分别固定以下聚合公式：同帧共同有效 K1/K2/K3 的该指标取中位数 → 同 sequence 的 frame 值取中位数 → 同 subject 的 sequence 值取中位数 → 所有有效 subject 等权算术平均，附人物中位数与逐人配对变化。有效机位由数据 QA 冻结；各方法使用相同参考点和相同机位，方法未命中不能成为删除参考点的理由。某 sequence 无参考时明确记缺失，同时报告每人实际 sequence 覆盖。

这轮新增 posterior ROI 和 sequence 等权层，与历史 BEHAVE V2.3 的全帧 subject 聚合不同，因此 31.17→17.80 mm 只作历史上下文。若需数值对账，另按旧区域/旧聚合复算附表，不把两个口径混成同一张改进表。

独立 depth 为主证据；`person_fit.ply` 仅作 fitted reference。不能直接对 MHR/SMPL 不对应的顶点算 PVE；支持性比较使用相同坐标下的表面距离。单独列 K0 改善但 held-out 退化的帧。

交付：冻结输入/评价索引、预执行合同与 hash、缓存 Mesh/参数/优化点、逐机位与逐帧表、逐人表、全部对照图、camera QA、执行账本、运行前后完整性和失败记录。

完成条件：表明独立机位结果的方向、尾部误差、有效覆盖与失败。以同向改善人数、逐人配对变化和 P95/覆盖一起判断；不设“必须达到 3.66 mm”目标。若后背可见覆盖不足，只能给覆盖范围内的结论，并用元数据预先选择另一个 cohort 形成新版本。

## 8. P4：同一表面上的拓扑传播与参考＋规则对照

**回答：表面几何固定后，个体参考信息是否能解决剩余的点位偏移？**

T0：固定 canonical face+barycentric 传播。

T1-proxy：沿用当前 Mesh 插值代理与规则，仅检查流程及与 T0 的分歧；不能用它评判谁正确。

T1-reference：采用可靠来源的独立参考标志和个体比例，再经同一规则引擎及同一表面投影得到目标。逐点按该点定位标准核实所需信息；MHR 动画关节、mask 分位水平不直接命名为 C7/T3/T5/T9/L2。骨度比例与体表标志可互相核对的条件必须逐点明确。

开始先用 Rigid 与 Rigid+D 两种表面，保持输入参考完全一致；再将同一可靠参考放到五种表面，拆开几何与对应影响。输入参考与最终评价目标要区分来源；不能把某目标自身标签作为输入，再用它评价独立定位准确率。

数据资格决定能回答的层级：

- 只有工程代理：报告传播稳定性、规则可计算性和方案分歧。
- 有来源已核验的二维目标：报告二维投影误差、覆盖和失败；保留相机/几何混合误差的限制。
- 有独立校准三维目标：再报告欧氏、切向/法向误差和每点/每人的 P95。

医生可以在工程链完整后参与，但可靠穴位参考到位前不输出“穴位定位已准确”的结论。当前 AI 标注全部保存为代理版本，原图/JSON 与未来独立标注不混写。

交付：每表面 T0/T1-proxy/可用时 T1-reference 的逐点输出、输入来源、规则中间量、对应图和误差/分歧分开报告。

## 9. P5：按结果决定训练和论文方法

| D 在独立机位也改善，点位切向移动有限且局部质量可解释 | 保留 Rigid+D 工程基线，重点研究可靠参考与个体对应 |
| K0 改善但独立机位退化，或形变破坏局部网格 | 分析对应/可见观测与形变约束，建立新版本；冻结旧失败结果 |
| 几何合同仍主导投影错位 | 查数据配准与标定；不以训练吸收坐标错误 |
| 独立参考＋规则明显改善目标，自动参考失败 | 训练参考标志/对应模块 |
| 独立参考也不能改善 | 核对目标定义、规则适用条件与参考可靠性 |
| 可靠标签缺失 | 继续工程流程和几何研究，医学准确率及穴位监督训练保持未验证 |

候选论文主线为**观测驱动表面恢复与个体体表对应的联合建模**，不是把已完成的拟合残差重新命名为穴位准确率。以下是待证据筛选的原型设计，尚不是已确认创新：

- 全身初始化：保留冻结 SAM3D ViT-H + MHR。它提供单图 Mesh 和结构先验；其官方公开实现支持 keypoint/mask prompts，[官方说明](https://github.com/facebookresearch/sam-3d-body)。本轮不随最新模型列表切换历史 checkpoint。
- RGB 特征：先核实冻结 SAM image encoder 中间特征能否稳定缓存；官方推理仓库不自动等于完整训练框架。
- depth 分支：K0 原始有效点反投影，使用共享 MLP 与局部邻域聚合，先做轻量原型；RGB/depth 必须为真实配对观测。
- 表面分支：融合图像/点云特征与 MHR posterior graph，预测局部几何残差，先与当前 Rigid+D 比较。
- 对应分支：在同一恢复表面上预测参考位置或切向定位修正，再投影并保存 face/barycentric；对应分支不靠移动整张表面刷目标距离。
- 联合损失：训练视角表面、可见轮廓/重投影、可靠参考/目标监督、局部网格正则；没有标签的项明确不启用，代理标志不得伪装独立监督。权重只用开发/验证数据选择。
- 训练顺序：先冻结 SAM/MHR、训练新分支并做最小 batch profiling；有独立收益后，再消融 decoder/adapter 微调。大规模 backbone 重训不作为默认起点。

MHR 的可微参数优化能力有官方实现支持，[MHR 文档](https://github.com/facebookresearch/MHR)。当前 freeform D 之后的网格仍需显式保存残差，不能只保存 MHR pose/shape 就声称可重建最终表面。

训练前必须完成近邻工作检索：RGB-D HMR、局部/非刚性表面配准、dense correspondence、体表 landmark 与穴位规则。逐项证明结构解决的可辨识问题、简单强基线无法解决的误差与数据条件；没有完成这一步不宣称新架构足够 MICCAI/顶会创新。

关键模型对照预留为：直接二维关键点＋depth、T0、T1-reference、传统平滑非刚性配准、仅几何分支、仅对应分支、联合模型。当前无可靠标签时，直接关键点模型和对应训练是候选，不能填成已运行对照。

新训练数据按实际可核验 subject 身份划分；新 test 在训练/调参前锁定，已消费的 20/5 人只作回归与工程诊断。数据规模由可取得独立人数与参考质量决定，不以帧数、目录数代替人数。本阶段无法据现有标签质量给出强接受承诺。

## 11. 第一项大任务的结束条件

P0/P1 完成；P2 给出独立机位证据或明确的覆盖不足结论；P3 输出实际资格清单；P4 至少完成代理链并明确独立参考还缺什么。最终报告必须逐条回答：

1. 表面改善在独立机位上是否保留？
2. D 引起的目标点移动主要在法向还是切向？哪些人/点有局部质量代价？
3. 固定拓扑传播与参考＋规则分歧在哪里？现有数据是否有资格判断哪条更准？
4. 下一笔资源应投入坐标与采集、几何模型，还是个体对应？
5. 当前能够支持哪些工程/研究主张，哪些必须等待独立目标参考和设备验收？

该报告形成后，再确定训练方向与论文主贡献。完成的标志是证据链可解释、可重算、选择依据清楚。
