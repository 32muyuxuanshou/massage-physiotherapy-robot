## 1. 项目概述

### 1.1 项目背景

颐本智能理疗系统是一套面向终端用户的智能理疗管理平台，通过与智能理疗机器人配合，实现从设备选择、AI智能分析、参数设置到理疗执行的完整流程。

### 1.2 项目定位

| 项目 | 内容 |
|------|------|
| 产品名称 | 颐本智能理疗系统 |
| 类型 | Web应用（SPA） |
| 核心功能 | 设备管理、AI分析、个性化理疗、实时监控 |
| 目标用户 | 需要理疗服务的终端用户 |
| 当前版本 | V0.1 - 一期核心功能完成 |
