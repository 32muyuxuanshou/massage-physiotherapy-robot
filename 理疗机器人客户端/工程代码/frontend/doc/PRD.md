**版本**: V0.1

**作者**: 开发团队

---

## 1. 项目概述

### 1.1 项目背景

随着人们对健康意识的不断提升，智能理疗设备逐渐进入家庭和医疗机构。传统的人工理疗存在效率低、标准化程度低等问题，而智能理疗系统可以通过AI分析实现个性化的理疗方案，提高理疗效果和用户体验。

颐本智能理疗系统是一套面向终端用户的智能理疗管理平台，通过与智能理疗机器人配合，实现从设备选择、AI智能分析、参数设置到理疗执行的完整流程。

### 1.2 产品定位

| 项目 | 描述 |
|------|------|
| 产品名称 | 颐本智能理疗系统 |
| 产品类型 | Web应用（智能理疗管理平台） |
| 核心功能 | 设备管理、AI智能分析、个性化理疗方案、实时理疗监控 |
| 目标用户 | 需要理疗服务的终端用户 |
| 使用场景 | 家庭理疗、康复中心、医疗院所 |
| 当前版本 | V0.1 - 一期核心功能完成 |

### 1.3 核心价值

1. **智能化**: AI辅助分析，自动识别理疗区域
2. **个性化**: 多种理疗手法可选，参数灵活调节
3. **可视化**: 相机实时图像展示理疗状态
4. **易用性**: 简洁直观的操作界面

## 2. 用户需求分析

### 2.1 用户画像

| 特征 | 描述 |
|------|------|
| 年龄 | 25-60岁 |
| 技术能力 | 中等偏上，能熟练使用智能手机/Web应用 |
| 健康需求 | 有理疗需求，关注健康管理和康复理疗 |
| 使用频率 | 每周1-3次 |

### 2.2 用户痛点

1. 不清楚应该选择哪种理疗方式
2. 不知道理疗参数如何设置
3. 理疗过程无法直观了解进度
4. 理疗参数无法个性化定制

### 2.3 用户流程

```
用户登录 → 选择设备 → AI分析 → 设置手法 → 理疗执行 → 结束
```

## 6. 页面原型描述

### 6.1 登录页

**布局**: 左右分栏
- 左侧: 系统名称、副标题、功能图标组
- 右侧: 登录卡片（手机号、密码、登录按钮、辅助链接）

**关键元素**:
- Logo/系统名称: "颐本智能理疗系统"
- 输入框: 手机号、密码（胶囊形）
- 按钮: "登 录"（橙色）
- 版权: "@2026 颐本智能理疗系统"

### 6.2 首页/设备选择页

**布局**: 垂直三段式
- 顶部: 导航栏（首页图标 + 进度条 + 用户信息）
- 中部: 设备列表（4个设备卡片）
- 底部: "下一步"按钮

**关键元素**:
- 设备卡片: 图标 + 名称 + 型号 + 状态指示灯
- 连接按钮: "已连接"/"已断开"
- 进度条: 步骤1高亮

### 6.3 AI分析页

**布局**: 垂直三段式
- 顶部: 导航栏 + 进度条
- 中部: 相机实时图像容器
- 底部: 操作按钮组

**关键元素**:
- 相机图像: 实时显示设备采集的画面
- 按钮: 采集图像、智能分析、设置手法、下一步
- 进度条: 步骤2高亮

### 6.4 理疗手法选择弹窗

**布局**: 居中弹窗
- 标题: "选择理疗手法"
- 内容: 手法卡片 + 时长滑块 + 已选标签
- 底部: "确认"按钮

**关键元素**:
- 手法选项: 推拿、点穴、揉捏、拍打
- 时长滑块: 0-60分钟
- 已选标签: 显示已选项

### 6.5 理疗管理页

**布局**: 垂直三段式
- 顶部: 导航栏 + 进度条
- 中部: 相机图像 + 剩余时间浮层
- 底部: 设备信息 + 操作按钮

**关键元素**:
- 剩余时间: 右下角显示
- 参数设置: 高度/速度/力度滑块
- 控制按钮: 重新选择、参数设置、开始/结束

## 7. 数据模型设计

### 7.1 用户信息

```typescript
interface UserInfo {
  id: string;
  phone: string;
  name: string;
  avatar: string;
}
```

### 7.2 设备信息

```typescript
interface Device {
  id: string;
  name: string;
  icon: string;
  model: string;
  status: {
    camera: 'online' | 'offline';
    arm: 'online' | 'offline';
    head: 'online' | 'offline';
  };
  connected: boolean;
}
```

### 7.3 理疗手法

```typescript
interface TherapyMethod {
  type: 'tuina' | 'xuewei' | 'niannie' | 'paida';
  name: string;
  duration: number; // 分钟
}
```

### 7.4 理疗参数

```typescript
interface TherapyParams {
  height: number;      // 0-100
  speed: number;       // 0-100
  intensity: number;    // 0-5
}
```

### 7.5 理疗状态

```typescript
type TherapyStatus = 'idle' | 'connecting' | 'ready' | 'running' | 'completed';
```
