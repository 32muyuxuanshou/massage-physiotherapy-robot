## 项目简介

颐本智能理疗系统是一套面向终端用户的智能理疗管理平台，通过与智能理疗机器人配合，实现从设备选择、AI智能分析、参数设置到理疗执行的完整流程。

**产品定位**: Web应用（SPA）
**核心技术**: Vue 3 + Vite + Pinia + Vue Router
**当前版本**: V0.1 - 一期核心功能完成

## 技术架构

```
┌─────────────────────────────────────────────────────────┐
│                    前端应用 (SPA)                        │
├─────────────────────────────────────────────────────────┤
│  ┌─────────┐  ┌─────────┐  ┌─────────┐  ┌─────────┐   │
│  │ Vue 3   │  │ Router  │  │ Pinia   │  │ axios   │   │
│  │(框架)   │  │(路由)   │  │(状态)   │  │(HTTP)  │   │
│  └─────────┘  └─────────┘  └─────────┘  └─────────┘   │
└─────────────────────────────────────────────────────────┘
```

### 核心技术栈

| 类别 | 技术 | 版本 |
|------|------|------|
| 核心框架 | Vue 3 | ^3.4.0 |
| 构建工具 | Vite | ^6.4.3 |
| 路由 | Vue Router | ^4.2.0 |
| 状态管理 | Pinia | ^2.1.0 |
| HTTP客户端 | Axios | ^1.19.0 |
| 图标 | Lucide Vue | ^0.300.0 |
| CSS预处理器 | SCSS | ^1.69.0 |

## 状态管理

使用Pinia进行全局状态管理：

| Store | 管理内容 |
|-------|---------|
| userStore | 用户信息、登录状态 |
| deviceStore | 设备列表、连接状态 |
| therapyStore | 理疗参数、手法选择、计时器 |

4. ✅ 响应式布局优先桌面端，移动端作为后续优化
