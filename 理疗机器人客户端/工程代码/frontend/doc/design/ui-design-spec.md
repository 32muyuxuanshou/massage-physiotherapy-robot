# UI设计规范文档

**版本**: V0.1
**日期**: 2026-04-10
**状态**: 一期核心功能完成

## 1. 设计概述

### 1.1 产品定位
- **产品名称**: 颐本智能理疗系统
- **产品类型**: 医疗康复/健康管理类Web应用
- **核心理念**: 专业理疗解决方案，智能化健康体验
- **目标用户**: 需要理疗服务的终端用户

### 1.2 设计风格
- **整体风格**: 现代、简约且具有亲和力
- **设计语言**: 新拟态(Neumorphism)与柔和极简主义结合
- **图形语言**: 大圆角设计，去除尖锐感，增强安全感和亲切感

---

## 2. 色彩规范

### 2.1 色彩体系

| 色彩名称 | 色值 | 用途 |
|---------|------|------|
| 主色调(橙褐色) | #E68A4F / #F28C55 | 按钮、强调色、选中状态 |
| 背景色(米黄色) | #FFF2E6 / Cream | 主背景、卡片背景 |
| 辅助橙 | #F28C55 | 进度条激活状态、次级按钮 |
| 浅橙色 | #FFE4D6 | 按钮悬停状态、选中项背景 |
| 深褐色 | #5D4E37 | 标题文字、主要文字 |
| 浅灰色 | #F5F5F5 | 未选中状态背景 |
| 成功绿 | #4CAF50 | 设备连接正常状态指示 |
| 警告红 | #F44336 | 设备断开/异常状态指示 |

### 2.2 色彩心理
- **暖色调**: 营造健康、专业且温馨的医疗科技氛围
- **橙色系**: 代表活力和理疗热度
- **米色系**: 代表放松和专业

## 3. 布局规范

### 3.1 页面结构

```
┌─────────────────────────────────────────┐
│  顶部导航栏 (Header)                    │
│  [首页图标] [进度条] [用户信息]         │
├─────────────────────────────────────────┤
│                                         │
│           主要内容区域                   │
│         (Main Content Area)             │
│                                         │
├─────────────────────────────────────────┤
│  底部操作栏 (Footer Action Bar)         │
│  [功能按钮组]                            │
└─────────────────────────────────────────┘
```

### 3.2 布局特点
- **顶部导航**: 固定高度约60px，包含首页入口、流程进度条、用户信息
- **内容区域**: 自适应高度，使用大圆角矩形容器
- **底部操作栏**: 固定高度约80px，包含主要操作按钮

### 3.3 响应式断点
- **桌面端**: >= 1200px
- **平板端**: 768px - 1199px
- **移动端**: < 768px

## 4. 组件规范

### 4.1 按钮

| 按钮类型 | 样式 | 用途 |
|---------|------|------|
| 主按钮 | 橙色实心背景，白色文字，圆角胶囊形 | 登录、下一步、确认、开始 |
| 次按钮 | 浅橙色/浅灰色半透明背景，深色文字 | 重新采集、重新分析、上一步 |
| 图标按钮 | 圆形/圆角矩形，浅色背景 | 参数设置、重新选择 |

- **圆角**: 胶囊形设计 (border-radius: 999px)
- **高度**: 44px - 56px
- **内边距**: 16px 32px

### 4.2 输入框

- **样式**: 胶囊型（全圆角）设计
- **背景**: 浅肤色，与背景区分
- **图标**: 左侧带图标标识（手机、锁头等）
- **悬停/聚焦**: 边框颜色加深

### 4.3 进度条

- **结构**: 三步骤流程指示器
- **状态**:
  - 已完成: 实心橙色圆点
  - 当前: 橙色加粗，空心或实心圆点
  - 未开始: 灰色圆点
- **连接线**: 虚线 + 箭头

### 4.4 设备卡片

- **布局**: 列表式布局
- **元素**:
  - 左侧: 设备图标 + 标题 + 型号
  - 中间: 状态指示灯（相机、机械臂、按摩头）
  - 右侧: 连接状态按钮
- **选中状态**: 白色背景 vs 浅肤色背景

### 4.5 弹窗/Modal

- **样式**: 大圆角白色卡片
- **圆角**: 24px - 32px
- **阴影**: 细微阴影效果
- **关闭按钮**: 右上角 × 图标

### 4.6 滑块组件

- **样式**: 横向时间轴
- **刻度**: 0-60分钟
- **指示器**: 橙色填充表示已选区域
- **数值显示**: 实时数值 + 时钟图标

## 5. 字体规范

### 5.1 字体家族
- **主字体**: 系统默认无衬线字体 (PingFang SC, -apple-system, Segoe UI)
- **数字**: 等宽数字字体

### 5.2 字号层级

| 层级 | 字号 | 字重 | 用途 |
|-----|------|------|------|
| H1 | 28px | Bold | 页面标题 |
| H2 | 22px | SemiBold | 卡片标题 |
| H3 | 18px | Medium | 模块标题 |
| Body | 16px | Regular | 正文内容 |
| Small | 14px | Regular | 辅助说明 |
| Caption | 12px | Regular | 版权、状态标注 |

---

## 6. 图标规范

### 6.1 图标风格
- **类型**: 线性图标 (Outline Icons)
- **线条粗细**: 1.5px - 2px
- **圆角**: 图标转角圆润处理

### 6.2 常用图标
- 首页: 房屋形状
- 用户: 人物头像
- 相机: 拍照功能
- AI: 核心/智能分析
- 设置: 齿轮图标
- 下一步: 箭头/播放图标
- 关闭: × 图标

## 8. 交互动效

### 8.1 过渡效果
- **时长**: 200ms - 300ms
- **曲线**: ease-in-out

### 8.2 状态反馈
- **按钮悬停**: 背景颜色加深
- **按钮点击**: 轻微缩放效果
- **卡片选中**: 背景明暗变化
